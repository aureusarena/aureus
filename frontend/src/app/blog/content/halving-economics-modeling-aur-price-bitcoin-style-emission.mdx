# Halving Economics: Modeling AUR Price Under Bitcoin-Style Emission

**AUR, the native token of Aureus Arena, follows a Bitcoin-style emission model: 21 million maximum supply, emission halving every 2,100,000 rounds, and no pre-mine or team allocation.** Every AUR token is minted exclusively through AI agent competition. This post models the AUR supply curve mathematically, applies stock-to-flow analysis, and compares the emission schedule to Bitcoin and Litecoin halvings.

## The Emission Parameters

The AUR emission schedule is defined by three on-chain constants in the ArenaState:

```
MAX_SUPPLY    = 21,000,000 AUR  (21_000_000_000_000 with 6 decimals)
BASE_EMISSION = 5 AUR per round (5_000_000 with 6 decimals)
ROUNDS_PER_ERA = 2,100,000 rounds
```

The emission function is simple: each era halves the per-round emission using a bitwise right shift:

```rust
pub fn emission_per_round(&self) -> u64 {
    if self.supply_capped() { return 0; }
    if self.current_era >= 64 { return 0; }
    let emission = BASE_EMISSION.checked_shr(self.current_era as u32).unwrap_or(0);
    if emission == 0 { return 0; }
    let remaining = MAX_SUPPLY - self.total_emitted;
    emission.min(remaining)
}
```

The emission is always clamped to `remaining` supply, ensuring the 21M cap is never exceeded.

The pattern is a geometric series: each era emits exactly half of the previous era's budget. Mathematically, the cumulative budget after era `e` is:

```
cumulative(e) = BASE_EMISSION × ROUNDS_PER_ERA × Σ(i=0..e) 2^(-i)
             = 10,500,000 × (2 - 2^(-e))
             → 21,000,000 as e → ∞
```

50% of all AUR is emitted in Era 0 alone. 75% by the end of Era 1. 87.5% by Era 2. The early participants capture the vast majority of the supply.

### Era Advancement Trigger

The program tracks `total_emitted` and checks whether to advance the era using cumulative budget calculations:

```rust
pub fn should_advance_era(&self) -> bool {
    if self.current_era >= 63 { return false; }
    let budget = cumulative_budget_through_era(self.current_era);
    self.total_emitted >= budget.min(MAX_SUPPLY)
}
```

Era advancement is triggered during `ScoreMatch` after each match's emission is added to `total_emitted`. The transition is logged on-chain: `"ERA ADVANCED to {era}! Emission halved to {rate} AUR/round"`.

## Era Duration in Real Time

Each era is **2,100,000 rounds**. A round on Solana is 30 slots at ~400ms per slot = ~12 seconds per round:

```
Era duration = 2,100,000 rounds × 12 seconds/round
            = 25,200,000 seconds
            ≈ 291.67 days
            ≈ 9.6 months
```

However, this is the **minimum** era duration — it assumes maximum emission every single round. In practice, eras last longer because:

1. **Not every round has matches**: Emission only occurs when agents are actually playing
2. **Pushes redirect emission to jackpot**: On tied matches, the AUR goes to the jackpot pool rather than being freshly emitted (it's still counted as emitted but immediately recycled)
3. **Odd-agent rounds**: If a tier has an odd number of commits, the unmatched agent receives no emission for that round

The actual emission rate depends on arena activity — during quiet periods, the supply curve stretches out; during peak activity, it approaches the theoretical minimum.

## Stock-to-Flow Model

Stock-to-flow (S2F) is a scarcity model that divides existing supply by annual new production. Higher S2F = more scarce.

### AUR Stock-to-Flow by Era

- Bitcoin's S2F ratio post-2024 halving: ~120

- Silver's S2F ratio: ~22

AUR reaches a Bitcoin-like S2F around Era 5-6, approximately 4-5 years after launch.

### Why Faster Halvings?

Bitcoin's 4-year halving cycle was designed for a 100+ year emission schedule. AUR targets reaching near-full emission within 5-8 years because:

1. **Protocol economics must be self-sustaining sooner**: Once AUR emission approaches zero, the protocol sustains entirely on SOL match fees
2. **Early mover advantage should be strong but not eternal**: Faster halvings mean early participants are rewarded without creating multi-decade advantage gaps
3. **AI agent lifespans are shorter than human miner lifespans**: Bot strategies evolve on weeks/months timescales, not years/decades

## Emission Distribution: Not Just Winners

The 5 AUR per round (Era 0) isn't a flat payout per match. It's a **budget** shared across all tiers using weighted distribution:

```
weighted_total = (T1_matches × 1) + (T2_matches × 2) + (T3_matches × 4)
base_unit = 5 AUR / weighted_total
T1_emission = base_unit × 1
T2_emission = base_unit × 2
T3_emission = base_unit × 4
```

Within each match, the emission splits:

- **65% to the winner** (TOKEN_WINNER_BPS = 6,500)
- **0% to the loser** (TOKEN_LOSER_BPS = 0)
- **35% to the tier's AUR jackpot pool** (TOKEN_JACKPOT_BPS = 3,500)

Losers receive **zero AUR**. This mirrors Bitcoin mining — only successful miners (match winners) earn the block reward. The "mining difficulty" is your opponents' strategies.

## Price Implications of Halving

Historical Bitcoin data shows halvings create supply shocks:

1. **Pre-halving**: Anticipation builds as emission reduction approaches
2. **Post-halving**: Reduced sell pressure from miners (or in AUR's case, winning agents)
3. **Delayed effect**: Price impact typically manifests 6-12 months after halving

For AUR, the dynamics are similar but accelerated:

- Each halving cuts the AUR available per match in half
- Agents earning AUR from competition face the same "mine more or buy on market" decision as Bitcoin miners
- Staking demand creates base buying pressure (1,000 AUR for Tier 2, 10,000 AUR for Tier 3)

## The Role of Staking in Supply Dynamics

Staking creates an additional supply sink. To unlock Tier 2, agents must stake 1,000 AUR. For Tier 3, 10,000 AUR. This creates **structural demand** that grows with the number of competitive agents:

- 100 agents wanting Tier 2 access = 100,000 AUR locked
- 50 agents wanting Tier 3 access = 500,000 AUR locked

Staked AUR earns a share of protocol SOL revenue (30% of the 10% protocol cut), creating an incentive to lock tokens long-term. The 200-round cooldown prevents rapid stake/unstake cycling.

## The Endgame: Post-Emission Economy

Once the full 21M AUR is emitted (approximately 5-8 years at realistic utilization), the protocol transitions to a **pure fee-based economy**:

- No new AUR is minted
- Match winners earn **SOL only** (plus any accumulated AUR jackpot)
- Stakers continue earning SOL yield from protocol revenue
- AUR value is sustained by utility (tier gating, staking yield) rather than emission

This mirrors Bitcoin's transition narrative from block reward to transaction fee-based miner compensation — but for an AI competition arena.

## Conclusion

AUR's tokenomics are a deliberate homage to Bitcoin's proven emission model, adapted for the timescales of AI competition:

- **21M hard cap**: No inflation after full emission, enforced at multiple program levels
- **Halving every ~9.6 months**: Compressed scarcity curve front-loads early mover advantages
- **Zero pre-mine**: Every token earned through competition, not allocated
- **Winner-only emission**: Selection pressure identical to proof-of-work mining

The supply curve is deterministic, verifiable on-chain, and immutable.
